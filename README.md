# Juriscont Corporativo

Bufete de abogadas y contadoras en Santa Rosa, El Oro, con 15 años de experiencia.

## Descripción del Proyecto
Página web estática moderna, elegante y de alto rendimiento. Diseño "oscuro elegante" (dark theme) que resalta los colores corporativos, transmitiendo profesionalismo y prestigio.

## Stack Tecnológico
- HTML5 Semántico
- SCSS (Arquitectura modular)
- JavaScript Vanilla
- Hosting: Cloudflare Pages

## Estructura de Archivos
- `assets/scss/`: Estilos del proyecto.
- `assets/js/`: Lógica interactiva.
- `index.html`: Punto de entrada principal.
